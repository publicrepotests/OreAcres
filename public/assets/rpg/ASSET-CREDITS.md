# Ore Acres RPG Asset Notes

## In-house generated maps

- `world/emberfall-highlands.png` was generated for Ore Acres and authored for this project.
- `world/moonfen-marsh.png` was generated for Ore Acres and authored for this project.
- `world/frostmere-coast.png` was generated for Ore Acres and authored for this project.
- `world/sunscar-expanse.png` was generated for Ore Acres and authored for this project.
- `world/orehaven-guildhall.png` was generated for Ore Acres and authored for this project.
- `atlas/characters.png` contains the high-detail creature and NPC atlas used for world encounters.
- `portraits/npc-atlas.png` includes four additional Guild Hall portraits generated for Ore Acres and authored for this project.
- `portraits/npc-atlas-v2.png` preserves the original eight NPC cells and replaces the four Guild Hall cells with project-authored, palette-reduced pixel treatments generated and normalized for a consistent in-game portrait style.
- `creatures/forest-wolf-sheet-v2.png` is a project-authored, pose-preserving four-direction wolf redraw generated and normalized for the game's detailed pixel-creature style.
- `creatures/briar-treant-idle.png` is an in-house generated four-frame creature strip for the Briarwild rare spawn.
- `creatures/briar-treant-rootwake.png` is an in-house generated six-frame attack strip for the Briar Treant's Rootwake ability.
- `creatures/ashwing-drake-sheet-1024.png` is an in-house generated and normalized sixteen-frame directional creature sheet for Emberfall's Ashwing Drake.
- `creatures/dune-stalker-sheet-1024.png` is an in-house generated and normalized sixteen-frame directional creature sheet for Sunscar's Dune Stalker.
