# LPC Hand Tool Credits

The axe, hammer, pickaxe, and fishing-rod animation layers in this directory come from the Universal LPC Spritesheet Character Generator hand-tool collection.

- Source: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator
- Original collection: https://opengameart.org/content/lpc-hand-tools
- Axe, hammer, and pickaxe authors: bluecarrot16, JaidynReiman, Pierre Vigier (pvigier), and Tuomo Untinen (reemax)
- Fishing-rod author: bluecarrot16
- License selected for this project: CC BY 4.0 or later
- Local modifications: files were renamed by activity and are tinted at runtime to match equipment tiers.

The full upstream project provides additional license options and asset-specific metadata in its `CREDITS.csv` and tool sheet definitions.
